# Installer features

| Feature | What the person does | File |
|---|---|---|
| install | Runs the one-line installer on a computer that has never had the app | [install.md](install.md) |
| run | Types `sports`, or opens Sports CLI from Applications | [install.md](install.md) |
| help | Has an install fail, and pastes the copied message into an AI assistant | [help.md](help.md) |
| uninstall | Types `sports --uninstall` or double-clicks Uninstall Sports CLI | [uninstall.md](uninstall.md) |
| wrappers | Downloads and double-clicks an installer or uninstaller | [uninstall.md](uninstall.md) |
